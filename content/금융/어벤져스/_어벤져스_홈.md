# 🦾 어벤져스 금융 분석팀

> **가디언즈가 매시·매일 1차 산출물을 만들면, 어벤져스가 그것을 종합·분석·블로그로 정리합니다.**
> 가디언즈 = 작가팀, 어벤져스 = 편집부 + 데이터 분석가.

## 👥 라인업

| 페르소나 | 역할 | 주기 | 출력 |
|---|---|---|---|
| 🌟 **Lumi** | 가디언즈 산출물 큐레이션 → 일일 블로그 1편 | 매일 21:00 | [[블로그]] |
| 🏹 **Hawkeye** | 연기금·기관·외국인 매매 추이 분석 | 평일 17:00 | [[연기금추적]] |

## 📅 오늘 작성된 글 (dataview)

```dataview
TABLE author, category, time
FROM "금융/어벤져스"
WHERE date = date(today)
SORT time DESC
```

## 📖 이번 주 어벤져스 작성 통계

```dataview
TABLE length(rows) as "글 수"
FROM "금융/어벤져스"
WHERE date >= date(today) - dur(7 days)
GROUP BY author
SORT length(rows) DESC
```
