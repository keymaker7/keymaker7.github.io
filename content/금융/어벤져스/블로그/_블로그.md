# 🌟 블로그

> **주기**: 매일 21:00

## 📅 최근 글

```dataview
TABLE WITHOUT ID
    file.link as "제목",
    persona as "담당",
    file.cday as "날짜"
FROM "금융"
WHERE category = "블로그" AND !contains(file.name, "_")
SORT file.ctime DESC
LIMIT 30
```
