# 🗡️ 용어

> **담당**: 가모라  
> **주기**: 매시 10분  
> **설명**: 주식·금융 용어를 중학생 눈높이로 정의

## 📅 최근 글

```dataview
TABLE WITHOUT ID
    file.link as "제목",
    persona as "담당",
    file.cday as "날짜"
FROM "금융"
WHERE category = "용어" AND !contains(file.name, "_")
SORT file.ctime DESC
LIMIT 30
```
