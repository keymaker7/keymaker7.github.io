# 🦝 일일추천

> **담당**: 로켓  
> **주기**: 평일 08:10  
> **설명**: 오늘의 추천 종목 10개 (수익형 5+미래지향 5)

## 📅 최근 글

```dataview
TABLE WITHOUT ID
    file.link as "제목",
    persona as "담당",
    file.cday as "날짜"
FROM "금융"
WHERE category = "일일추천" AND !contains(file.name, "_")
SORT file.ctime DESC
LIMIT 30
```
