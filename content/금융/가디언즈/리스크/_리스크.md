# 🌑 리스크

> **담당**: 네뷸라  
> **주기**: 평일 09:30  
> **설명**: 변동성·악재 뉴스·손절 기준

## 📅 최근 글

```dataview
TABLE WITHOUT ID
    file.link as "제목",
    persona as "담당",
    file.cday as "날짜"
FROM "금융"
WHERE category = "리스크" AND !contains(file.name, "_")
SORT file.ctime DESC
LIMIT 30
```
