# 🚀 포트폴리오회의

> **담당**: 스타로드  
> **주기**: 일 21:00  
> **설명**: 주간 종합 회의록

## 📅 최근 글

```dataview
TABLE WITHOUT ID
    file.link as "제목",
    persona as "담당",
    file.cday as "날짜"
FROM "금융"
WHERE category = "포트폴리오회의" AND !contains(file.name, "_")
SORT file.ctime DESC
LIMIT 30
```
