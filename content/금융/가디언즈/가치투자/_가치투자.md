# 🏹 가치투자

> **담당**: 욘두  
> **주기**: 월 09:00  
> **설명**: 배당주·저PER 가치주·장기 보유 후보

## 📅 최근 글

```dataview
TABLE WITHOUT ID
    file.link as "제목",
    persona as "담당",
    file.cday as "날짜"
FROM "금융"
WHERE category = "가치투자" AND !contains(file.name, "_")
SORT file.ctime DESC
LIMIT 30
```
