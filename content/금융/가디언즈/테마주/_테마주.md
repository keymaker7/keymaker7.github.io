# ✨ 테마주

> **담당**: 어덤  
> **주기**: 수 12:00  
> **설명**: 이번 주 핫 테마 3 + 관련 종목

## 📅 최근 글

```dataview
TABLE WITHOUT ID
    file.link as "제목",
    persona as "담당",
    file.cday as "날짜"
FROM "금융"
WHERE category = "테마주" AND !contains(file.name, "_")
SORT file.ctime DESC
LIMIT 30
```
