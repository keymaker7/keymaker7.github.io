# 🌳 뉴스

> **담당**: 그루트  
> **주기**: 매일 11:45  
> **설명**: 글로벌 금융 소식 5건

## 📅 최근 글

```dataview
TABLE WITHOUT ID
    file.link as "제목",
    persona as "담당",
    file.cday as "날짜"
FROM "금융"
WHERE category = "뉴스" AND !contains(file.name, "_")
SORT file.ctime DESC
LIMIT 30
```
