# 🐕 매크로

> **담당**: 코스모  
> **주기**: 금 18:00  
> **설명**: 금리·환율·원자재 주간 흐름

## 📅 최근 글

```dataview
TABLE WITHOUT ID
    file.link as "제목",
    persona as "담당",
    file.cday as "날짜"
FROM "금융"
WHERE category = "매크로" AND !contains(file.name, "_")
SORT file.ctime DESC
LIMIT 30
```
