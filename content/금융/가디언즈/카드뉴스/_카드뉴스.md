# 🔪 카드뉴스

> **담당**: 드랙스  
> **주기**: 매시 30분  
> **설명**: 가모라 글을 8장 인스타 카드뉴스로 변환

## 📅 최근 글

```dataview
TABLE WITHOUT ID
    file.link as "제목",
    persona as "담당",
    file.cday as "날짜"
FROM "금융"
WHERE category = "카드뉴스" AND !contains(file.name, "_")
SORT file.ctime DESC
LIMIT 30
```
