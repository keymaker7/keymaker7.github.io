## 📅 오늘 작성된 글

### [어벤저스] 자동생성
```dataview
TABLE WITHOUT ID
    file.link as "제목",
    persona as "담당",
    file.cday as "날짜"
FROM "금융"
WHERE source = "어벤저스" AND file.cday = date(today)
SORT file.ctime DESC
```

### Guardians (Discord)
```dataview
TABLE WITHOUT ID
    file.link as "제목",
    persona as "담당",
    file.cday as "날짜"
FROM "금융"
WHERE source != "어벤저스" AND file.cday = date(today) AND !contains(file.name, "_")
SORT file.ctime DESC
```

## 📊 이번 주 통계

```dataview
TABLE WITHOUT ID
    persona as "담당",
    length(rows) as "글 수"
FROM "금융"
WHERE file.cday >= date(today) - dur(7 days) AND !contains(file.name, "_")
GROUP BY persona
SORT length(rows) DESC
```
