# 🧩 포토 콜라주 프레임 메이커

> **이미지 1장을 업로드하면 퍼즐처럼 조각내어 프레임 형태로 변환하고, PDF로 저장할 수 있는 무료 웹앱**

**바로 사용하기** 👉 [photo-collage-umber.vercel.app](https://photo-collage-umber.vercel.app)

---

## 이런 분께 추천합니다

- 캔바(Canva)에서 **커스텀 프레임**을 만들고 싶은 분
- 학급 활동 사진을 **퍼즐 콜라주**로 꾸미고 싶은 교사
- SNS에 올릴 **창의적인 포토 레이아웃**이 필요한 분
- 포토북·포스터에 넣을 **분할 프레임 이미지**를 만들고 싶은 분

---

## 핵심 기능

### 5가지 분할 방식

| 모드 | 설명 | 활용 예시 |
|------|------|-----------|
| 🔲 **격자** | 가로×세로 균등 분할 | 인스타 그리드, 포토북 |
| 🍕 **파이** | 원형 파이 슬라이스 | 원형 콜라주, 프로필 프레임 |
| 🧩 **직소 퍼즐** | 요철이 있는 진짜 퍼즐 조각 | 교실 게시판, 팀빌딩 활동 |
| ⬡ **벌집** | 육각형 벌집 패턴 | 트렌디한 SNS 포스트 |
| ▬ **스트립** | 세로 스트립 분할 | 배너, 북마크 디자인 |

### 세부 조절

- **조각 수**: 가로/세로 1~10개, 파이 2~20조각
- **간격**: 0~40px 조절 — 프레임 느낌의 핵심
- **모서리 둥글기**: 0~50px
- **배경색/테두리**: 자유 색상 지정
- **그림자**: 없음~강하게 4단계
- **캔버스 크기**: 1000~3000px (고해상도 인쇄 대응)

### 출력 포맷

- **PDF 저장** → 캔바에 업로드하면 커스텀 프레임으로 사용 가능
- **PNG 저장** → SNS·프레젠테이션·인쇄물에 바로 활용

---

## 사용법 (3단계)

### 1단계: 이미지 업로드
클릭 또는 드래그앤드롭으로 사진 1장을 업로드합니다.

### 2단계: 분할 설정
분할 방식(격자/파이/퍼즐/벌집/스트립)을 선택하고, 조각 수·간격·스타일을 조절합니다.

### 3단계: PDF 저장
**PDF 저장** 버튼을 누르면 A4/A3/Letter/정사각 크기로 PDF가 다운로드됩니다.

---

## 캔바 연동 활용법

1. 웹앱에서 이미지를 퍼즐 프레임으로 분할
2. **PDF 저장**으로 다운로드
3. 캔바에서 **업로드** → PDF 파일 선택
4. 캔바 캔버스에 배치하여 **커스텀 프레임**으로 활용
5. 각 조각 위에 텍스트, 스티커, 추가 이미지 배치 가능

---

## 기술 스택

- **프론트엔드**: Vanilla HTML/CSS/JavaScript (프레임워크 없음)
- **렌더링**: Canvas API (클립 경로 기반 퍼즐 조각)
- **PDF 생성**: jsPDF
- **배포**: Vercel (정적 호스팅)
- **데이터 처리**: 100% 브라우저 내 처리 (서버 전송 없음, 개인정보 안전)

---

## 보안 및 개인정보

- 업로드된 이미지는 **서버에 전송되지 않습니다**
- 모든 처리는 **브라우저 내에서만** 이루어집니다
- 외부 API 호출 없음 — 오프라인에서도 사용 가능
- 오픈소스 라이브러리(jsPDF)만 CDN으로 로드
