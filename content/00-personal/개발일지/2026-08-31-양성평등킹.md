# ⚖️ 양성평등 킹 개발일지

## 🎯 목표

킹수학([kingsmath.com](https://www.kingsmath.com)) 스타일로 양성평등 교육 게임을 만들고, 교실의 1인 1기기 환경에 맞춰 실시간 배틀로 확장한다. 초등·중등 수준별 문항으로 실제 사례까지 배울 수 있게.

👉 **플레이**: [king-equality.netlify.app](https://king-equality.netlify.app) (학생 참가) · [/teacher.html](https://king-equality.netlify.app/teacher.html) (교사 진행) · [/solo.html](https://king-equality.netlify.app/solo.html) (전자칠판 6인 터치판)

## 🔨 한 일 (시간순)

1. **킹수학 엔진 분석** — 공개 저장소(`kingsmath/web-games`, CC BY-NC 4.0)에서 소스를 받아 OX 골든벨 게임의 구조를 해부: 단일 HTML, 동물 팀 컬럼, 3-2-1 카운트다운, WebAudio 효과음, 챌린지/서바이벌 2모드
2. **솔로판 제작** — 그 엔진 위에 초등용 양성평등 문항 24개(직업·집안일·놀이·감정표현·언어습관 고정관념)를 얹어 배포
3. **멀티판 제작** — 카훗 방식으로 확장: 서버리스 함수 + Redis 폴링. 교사 화면(4자리 방 코드+QR, 진행 제어)과 학생 화면(각자 기기에서 답 터치) 분리. 속도 비례 점수(500~1000점), 3연속 정답 보너스, 전원 제출 시 조기 정답 공개
4. **콘텐츠 v2** — 초등/중등 수준 선택 추가. 중등 24문항은 개념·역사·제도·실존 인물 중심: 유리천장 지수, OECD 성별 임금격차, 뉴질랜드 1893 세계 최초 여성 참정권, 호주제 폐지, 히든 피겨스(캐서린 존슨), 말랄라, 빌리 진 킹의 1973 성 대결, 마리 퀴리, 한국 최초 여성 양의사 박에스더, 필즈상 미르자하니. '남자는 울면 안 된다'류 남성을 조이는 고정관념도 절반 가까이 배치
5. **검증** — Playwright로 교사+학생 브라우저 3개를 실제로 띄워 풀 게임 자동 주행 2회, API 플로우 검증, 에러 0

## 🧗 막힌 지점과 해결

- **서버리스 함수가 환경변수를 못 읽음** — CLI 수동 배포는 함수 런타임에 사이트 환경변수를 주입하지 않는다는 걸 진단용 함수를 배포해 실측으로 확인. 설정 파일을 배포 번들에 동봉하는 방식으로 해결
- **env 설정 CLI의 다중 인자 옵션이 조용히 실패** — 에러 없이 변수가 통째로 사라지는 사고. 기본 문법으로 재설정해 복구
- **학생 제출 함수 정의 누락** — 배포 전 E2E 자동 주행에서 발견. 이 게이트가 없었으면 수업 중에 터졌을 버그
- **정답 공개 시점의 순위 미반영** — 학생은 "+954점!"인데 교사 화면은 0점. 공개 시점에 이번 문제 점수를 미리 얹어 표시하도록 서버 수정
- **한국어 조사 버그** ("선생님라고") — 템플릿 치환식 문항의 고질병. 조사를 선택지 문자열 안에 포함시키는 패턴으로 회피

## 📚 배운 것

- 새 인프라 조합은 hello-world 하나로 먼저 스모크 테스트하고 본 배포에 들어갈 것 — 이번엔 배포 4회를 반복하고서야 원인을 찾았다
- 요구사항이 조각으로 도착하는 바이브 코딩에서는 시작 전 "대상·기기·인원" 3질문을 확정하는 것만으로 재작업이 크게 준다
- 배포 전 E2E 자동 주행 게이트는 이번에도 실전 버그 2개를 잡았다. 계속 간다
